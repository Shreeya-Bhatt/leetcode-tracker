# LeetCode Tracker

Personal log to track mandatory daily coding requirements.

## Structure

* **`Python/`** - Algorithms & data structures solutions.
* **`SQL/`** - Database queries.

## Daily Requirement

Each day, complete either:
* **Python:** 2 Easy **OR** 1 Medium
* **SQL:** 2 Easy **OR** 1 Medium

## Guidelines

* **Consistency:** Maintain a daily streak throughout the month.
* **Quality:** Focus on understanding the logic over just getting acceptance.
* **Logging:** Keep this repo updated alongside the shared spreadsheet.
